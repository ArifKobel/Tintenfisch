# Security

Tintenfisch processes PDF files entirely in the browser, so problems in the engine or the file handling can matter even without a server.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/ArifKobel/Tintenfisch/security/advisories/new), not in a public issue. Include the steps to reproduce and, if possible, a minimal file that triggers the problem.

You will get an answer as soon as possible. Once a fix is released, the advisory is published with credit to the reporter unless you prefer to stay anonymous.

## Supported versions

Only the latest version on `main`, which is what https://tintenfisch.app runs, receives fixes.
